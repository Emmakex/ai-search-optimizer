# AI Search Optimizer 0.5.1

AI Search Optimizer `0.5.1` is the submission-hardening patch prepared from the already accepted local-Free product line before WordPress.org submission.

## What changed from 0.5.0

The customer feature set and local-first privacy model are unchanged. This patch is intentionally narrow:

- aligns the plugin Version, connector version constant and WordPress Stable tag at `0.5.1`;
- replaces stale pre-GitHub-release wording in the packaged WordPress `readme.txt`;
- adds the concise `0.5.1` changelog entry required for the submission line;
- keeps both Plugin URI and Author URI absent, avoiding the equal-URI submission error class;
- preserves the existing Kairoseth support CTA contract, outbound-data allow-list, REST namespace, authorization model and storage behavior.

This GitHub Release does **not** mean the plugin is available on WordPress.org. `0.5.1` is the exact package intended for the separate WordPress.org submission/review gate. Until WordPress.org has actually accepted and published it, `ai-search-optimizer` remains only the target directory slug.
