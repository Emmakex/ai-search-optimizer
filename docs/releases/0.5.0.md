# AI Search Optimizer 0.5.0

AI Search Optimizer `0.5.0` is the first public GitHub release of the standalone WordPress plugin.

## What it does

AI Search Optimizer provides an account-free local WordPress workflow to:

- inspect AI-search readiness signals such as `robots.txt`, sitemap and existing `llms.txt` state;
- inventory eligible public WordPress content and public WooCommerce products;
- select resources and generate deterministic, source-grounded `llms.txt` content;
- validate and explicitly publish the generated content;
- read the public `/llms.txt` back independently and verify the exact SHA-256;
- choose preserve/delete behavior for published data during uninstall;
- optionally open a privacy-bounded Kairoseth support or custom-development request after an explicit administrator click.

The local Free workflow does not require a Kairoseth account, license or entitlement.

## WordPress.org status

This GitHub Release does **not** mean the plugin is available on WordPress.org. WordPress.org submission and external review are a separate Phase 5C gate. Until WordPress.org has actually accepted and published the plugin, `ai-search-optimizer` remains only the target directory slug.

## Claims boundary

AI Search Optimizer improves AI-search readiness and produces reproducible technical evidence. It does not guarantee ranking, citation, indexing, crawling, AI ingestion, training inclusion or endorsement by third-party providers.
